# DBMS-project
Its a lost and found management system using MySQL and NoSQL(Mongo_db). Using java and spring boot as backend and html, css , javascript, as frontend of the vs code. 
Features :
          User registration and login <br>
          Report and view items <br>
          Manage item claims <br>
          Store structured data in MySQL <br>
          Track activity logs using MongoDB <br>
